# SistemaVentasWeb

Proyecto académico desarrollado en Angular para la gestión y control de un sistema de ventas.

## Tecnologías utilizadas
* **Framework:** Angular
* **Lenguaje:** TypeScript, HTML5, CSS3

## Requisitos previos
Asegúrate de tener instalado [Node.js](https://nodejs.org/) en tu computadora.
